SafeWalk · 경쟁·유사 서비스 조사

SafeWalk 벤치마킹 노트

국내외 안전지도·안심귀가 서비스 8종을 조사해 각각의 특이점을 정리하고, SafeWalk에 실제로 가져온 기능과 의도적으로 가져오지 않은 기능을 기록합니다. 발표·보고서에서 "우리는 무엇이 다른가"를 설명할 때 이 문서를 근거로 쓰세요.

1안전 서비스의 세 가지 유형

조사한 서비스는 세 유형으로 나뉩니다. SafeWalk는 셋 중 가장 비어 있는 "사전 예방형" 자리에 서 있습니다 — 이것이 핵심 차별점입니다.

🗺 사전 예방형 — SafeWalk의 자리
나가기 전에 경로와 주변 안전 인프라를 확인하고 계획한다.
SafeWalk, SafetiPin, WalkSafe(일부), 생활안전지도
🚨 사후 대응형
사고 순간에 SOS를 보내고 증거를 남긴다.
bSafe, Noonlight, HollieGuard, 지자체 안심귀가 앱
👁 모니터링형
이동하는 동안 사람(관제사·보호자)이 지켜본다.
서울 안심이, 카카오맵 위치공유, Life360

2국내 플랫폼

플랫폼특이점SafeWalk와의 관계
서울 안심이 서울 전역 11만 대 CCTV를 관제센터와 연계. 귀가 모니터링(관제사가 실시간으로 지켜봄), 흔들기 긴급신고 → 경찰 출동, 폰 영상을 관제센터로 보내는 "안심영상" 사람+기관 인프라가 본질이라 개인 프로젝트가 재현 불가. "우리는 사전 예방을 한다"는 선 긋기의 기준점
경기 안전귀가 등
지자체 앱		 흔들기 SOS 시 관제센터+보호자에게 위치 전송, 지정 경로 이탈 감지 지자체별 파편화(경기도도 11개 시·군 미참여)가 한계. SafeWalk는 전국 공공데이터 기반이 역차별점
생활안전지도
(행안부)		 9대 분야 120여 종 주제도, 1~10등급 히트맵, 실시간 정보. SafeWalk의 데이터 원천 데이터는 압도적이지만 일반인에게 무겁다. SafeWalk의 "이용자 유형별 큐레이션 + 경로 점수화"가 이 틈새
카카오맵
톡친구 위치공유		 카톡 친구에게 실시간 위치·이동 경로 공유. 별도 앱 설치 불필요 "설치 장벽 없는 공유"가 배울 점 → SafeWalk도 링크·문자 기반 공유 채택

3해외 플랫폼

플랫폼특이점주목할 점
SafetiPin (인도) 시민이 지점을 9개 지표(조명·개방성·가시성·인적 밀도·보안·보도 상태·대중교통 접근·성별 이용·주관적 느낌)로 0~3점 평가하는 "안전 감사". 610만 건 누적 → 지역 안전점수·안전 경로 생성, 시 정부의 가로등 개선으로 연결 시설 데이터가 아니라 사람의 평가를 데이터로 만든 것이 핵심. SafeWalk의 "시민 안전 평가"의 원형
WalkSafe (영국) 범죄 신고 히트맵 회피 경로. HomeSafe: 예정 시각까지 미도착 시 보호자 자동 알림. 경찰·지자체가 인증한 "안전 공간"(Ask for Angela 참여 매장, 택시 승강장) 지도 표시 안심 타이머와 안심 편의점 레이어의 원형
bSafe (노르웨이) 음성 SOS, 라이브 영상 스트리밍, Follow Me GPS 트레일, 가짜 전화 사후 대응 특화. UX 아이디어만 참고
Noonlight (미국) 버튼을 누르고 있다가 놓은 뒤 PIN 미입력 시 자동으로 911 디스패치 기관 연동 없이는 재현 불가·재현 금지 영역
HollieGuard (영국) 흔들면 보호자 알림 + 주변 증거 녹화, 한 번 더 흔들면 고음 사이렌 + 플래시 사이렌+점멸은 웹만으로 구현 가능 → SafeWalk 긴급 버튼에 채택
Citizen (미국) 주변 사건·사고 실시간 알림 피드 실시간 신고 데이터가 없어 재현 불가

4현재 SafeWalk에 반영한 기능

2026-09-05 코드 기준입니다. 앞의 해외 서비스 비교는 2026-08 초기 조사 기록이며 최신 운영 현황·수치는 별도 확인이 필요합니다.

구현
안심 타이머
도로망 경로 조회 성공 후 예상시간에 여유 시간을 더한 타이머를 제안합니다. 경고 후 전화·문자는 사용자가 직접 실행합니다. 탭 종료 시 백그라운드 알림을 보장하지 않습니다.
js/timer.js
구현
긴급 도움
112·119 전화, 보호자 문자, 위치 복사, 사이렌·화면 점멸을 제공합니다. 실제 GPS를 확인하지 못하면 좌표 대신 위치 미확인 문구를 넣습니다.
js/emergency.js
구현
즐겨찾는 장소
사용자가 선택한 장소를 현재 기기에 저장합니다. 시민 안전 평가나 전체 사용자 공유 기능이 아닙니다.
js/audit.js
현재 미사용
시민 안전 평가·안심 편의점
초기 검토 아이디어입니다. 현재 audit.js는 즐겨찾기로 전환되었고 havens.js는 호환용 함수만 남아 있습니다. 과거 평가 Worker는 현재 화면과 연결되지 않습니다.

5의도적으로 가져오지 않은 것

발표에서 "안 한 것"을 먼저 말하면 신뢰가 생깁니다. 작동하는 척하는 안전 기능이 최악이기 때문입니다.

관제센터 연계·자동 신고·911식 디스패치 (안심이, Noonlight) — 기관 인프라 없이 흉내 내면 "누군가 지켜보고 있다"는 거짓 안심을 만든다. SafeWalk의 모든 연락은 사용자가 직접 버튼을 눌러 실행된다.
실시간 사건 알림 (Citizen) — 한국에 공개된 실시간 신고 데이터가 없다. 추측성 알림은 불안만 키운다.
자동 영상 녹화·증거 수집 (bSafe, HollieGuard) — 촬영·저장은 개인정보 문제가 따르고, 웹 앱이 백그라운드에서 안정적으로 할 수도 없다.
현재 점수는 경로 주변 시설 접근성의 참고값이며 시민 평가나 범죄 위험 예측을 포함하지 않습니다. 실제 구현은 코드 지도를 기준으로 확인합니다.
