SafeWalk v2.1 · 개발 가이드

SafeWalk 코드 지도

한 파일 4,000줄이던 index.html을 기능별 파일로 나눴습니다. 이 문서 하나로 어떤 기능이 어느 파일에 있는지, 코드가 어떤 순서로 움직이는지, 고칠 때 무엇을 조심해야 하는지를 파악할 수 있습니다.

1파일 구조

폴더 구조는 v2/index.html + css/ + js/ + assets/입니다. 카드 상단 색은 담당 영역을 뜻합니다.

2코드는 이런 순서로 움직인다

사용자가 "내 주변 안전지도 보기"를 누른 뒤 길찾기까지의 전체 흐름입니다. 각 단계 왼쪽이 담당 파일입니다.

main.js
인트로에서 유형 선택 → start()가 지도 화면으로 전환 Leaflet이 로드 안 됐으면 여기서 멈추고 안내 토스트를 띄움
map.js
initMap() → 지도 생성 → getGPS()로 내 위치 확인 위치 거부 시 포항 기본 좌표 사용. 이후 위치가 바뀔 때마다 마커만 이동
layers.js
fetchAll() → 생활안전지도에서 화면 범위 시설 조회 → 마커 표시 줌 14 미만이면 조회 안 함(줌 게이트). 500건 꽉 차면 그 지역 최소 줌을 올림
search.js
길찾기 버튼 → 검색 패널 → VWorld로 장소 검색 → 출발·도착 지정
route.js
runSearchRoute() → Worker 프록시 → 실패 시 OSRM → Valhalla 순으로 보행 경로 요청 3단 폴백. 전부 실패하면 직선 안내로 대체
route.js
경로를 구간으로 나눠 주변 시설 조회(회랑) → 안전도 점수 계산 → 패널 표시 시설 조회가 전부 실패하면 점수 대신 "측정 불가"를 표시(v2 변경)
chat.js
챗봇: "A에서 B까지" 문장 인식 → VWorld 후보 → 사용자 확인 → 위의 길찾기 실행 AI는 좌표를 만들지 않음. 일반 질문만 Cloudflare Workers AI로 전송

4v2에서 고친 것들

원본(../index.html)은 그대로 두었습니다. v2는 코드 리뷰에서 확인된 아래 문제들을 반영한 버전입니다. 원본과 비교하며 공부할 때 참고하세요.

보안
시설 팝업 XSS 방지 — layers.js, map.js
API 응답(이름·주소·전화번호)을 innerHTML에 넣기 전에 esc()로 이스케이프. 원본은 그대로 넣고 있었음.
버그
시설 조회 실패 시 가짜 점수 차단 — route.js
시설 조회가 전부 실패하면 "40점대 점수" 대신 측정 불가를 표시. 일부만 실패하면 경고 문구 추가. "점수가 없다 = 확인 못 했다"를 명확히.
버그
회랑 버퍼를 미터 기준으로 보정 — route.js
기존 고정값 0.0016°는 동서 방향으로 약 141m라서 판정 반경 150m보다 좁았음. 이제 위도별로 190m를 보장해 경계 시설이 누락되지 않음.
버그
km 단위 응답의 거리·시간 표시 오류 — route.js
getRouteSummary()에서 km→m 변환을 예상 시간 계산보다 먼저 수행하고, 500m 미만 경로에서도 변환이 작동하도록 판정 조건 개선.
버그
길찾기 중복 실행·뒤로가기 충돌 방지 — route.js
routeRunToken으로 진행 중이던 이전 계산을 무효화. 새 길찾기가 이전 결과에 덮어써지거나, 뒤로가기 중 오류로 패널이 "계산 중"에 멈추는 문제 해결.
속도
첫 화면 로딩 단축 — index.html, main.js
Leaflet을 defer로 로드(파싱 차단 제거), 로딩 화면은 DOMContentLoaded에서 숨김, 폰트 두께 4종→3종, 폰트·CDN preconnect 추가, CPTED 아이콘을 로컬 파일로 교체(정부 서버 대기 제거).
속도
안전도 계산 UI 멈춤 방지 — route.js
경로 사각형 밖 시설을 먼저 걸러내고, 경로 점이 800개를 넘으면 간격을 띄워 계산. 긴 경로에서 수 초씩 멈추던 문제 완화.
보안
CDN 무결성 검증(SRI) — index.html
Leaflet CSS·JS에 integrity 해시 추가. CDN이 변조돼도 브라우저가 로드를 거부.
버그
CDN 실패 시 흰 화면 방지 — main.js, map.js
Leaflet 의존 코드를 함수 안으로 옮겨, CDN이 죽어도 인트로는 뜨고 "시작" 시점에 안내 메시지를 보여줌.
버그
챗봇 오인식 보완 — chat.js
"지금까지 ~" 같은 시간 표현 차단어 보강. "장미마을"처럼 '을'로 끝나는 지명이 조사 제거로 깨지면 원래 이름으로 한 번 더 검색.
정리
중복 코드 통합 — layers.js
시설 조회 요청을 requestSafemapMarkers() 하나로 통합(기존 2곳 중복). 시설 이름·주소 추출도 getFacilityInfo()로 일원화.

5작업 규칙

외부 문자열은 무조건 esc(). API 응답·사용자 입력을 innerHTML에 넣을 때 예외 없음. textContent를 쓰면 esc() 불필요.
설정값은 config.js에서만 바꾼다. 다른 파일에 숫자를 직접 쓰지 말 것. 점수 기준을 바꾸면 인트로 안내 문구도 함께.
한 사람이 한 파일. 파일이 나뉜 이유가 이것. 같은 파일을 두 명이 동시에 고치면 합칠 때 충돌한다.
고치기 전에 원본과 비교한다. 같은 함수가 원본 index.html에도 있다. 동작이 다르면 4번 섹션의 "고친 것들"에 해당하는지 먼저 확인.
배포 도메인을 바꾸면 VWorld에 등록한다. config.js의 VWORLD_SERVICE_DOMAIN은 VWorld 키에 등록된 도메인과 일치해야 검색이 된다.
테스트는 두 가지 화면에서. PC 크롬 + 스마트폰(또는 개발자도구 모바일 모드). 이 앱은 모바일 대응 코드가 절반이다.
남은 숙제 (서버 쪽): Cloudflare Worker(safewalk-chat, safewalk-route)는 현재 누구나 호출할 수 있습니다. Worker 코드에서 Origin 헤더 확인을 추가하고, Cloudflare 대시보드에서 Rate Limiting 규칙(무료 1개)을 걸어두세요. 방치하면 외부인이 무료 사용량을 소진시킬 수 있습니다.

6다음에 만들면 좋은 기능

난이도 하(초록)는 반나절~하루, 중(주황)은 2~3일 분량입니다.

난이도 하
최근 목적지 저장
localStorage에 최근 5곳 저장. search.js의 검색 패널에 칩으로 표시.
난이도 하
경로 공유 링크
출발·도착 좌표를 URL 쿼리로. main.js 부팅 시 쿼리가 있으면 자동 길찾기.
난이도 하

난이도 중
야간 모드
Carto dark 타일 + CSS 변수 스왑. "밤길 안전"이라는 취지와 잘 맞음.
