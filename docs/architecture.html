SafeWalk 코드 지도

2026-09-05 수정 기준 · 현재 구현과 운영 범위

화면과 집계 기준

항목실제 동작
하단 시설 개수지도 전체 사각형 범위 안에서 조회된 고유 시설 데이터 건수입니다. 설정 패널에 가려진 지도도 포함합니다. 장비 수나 GPS 고정 반경 집계가 아닙니다.
조회 상태정상 조회 0건, 조회 실패, 표시 꺼짐(–), 일부 집계(+)를 구분합니다. 요청당 500건씩 최대 4페이지를 읽고 반복 페이지·상한을 감지합니다.
경로 주변 시설도로망 경로에서 150m 이내의 시설만 점수와 경로 시설 수에 반영합니다. 지도 표시 레이어와 별도로 조회합니다.
시설 접근성 점수치안시설 최대 17점, CCTV 11점, 비상벨 11점, 지킴이집 6점의 원점수를 100점으로 환산합니다. 기본 가산점과 짧은 거리 보정은 없습니다. 시설 0건은 0점, 조회 전부 실패는 측정 불가입니다.
이용자 유형유형별로 표시 레이어가 달라집니다. 점수는 모든 유형에 같은 시설 가중치를 적용합니다. 범죄주의구간·즐겨찾기는 점수에 포함되지 않습니다.

점수는 시설 접근성에 대한 설계상 참고값입니다. 통계적으로 검증된 범죄 위험 예측이나 최적 안전 경로를 뜻하지 않습니다.

위치와 보행 안내

  • map.js의 acceptGPSPosition()이 실제 GPS 측정 좌표·시각·정확도를 함께 기록합니다. 2분 이내 측정값만 현재 위치로 사용합니다.
  • 권한 거부 시 기본 좌표나 저장 좌표는 지도 중심에만 사용합니다. 긴급 문자·좌표 복사에 실제 현재 위치처럼 넣지 않습니다.
  • route.js가 프록시 → OSRM 보행 → Valhalla 순서로 도로망 경로를 요청합니다. 각 요청은 본문 수신을 포함해 최대 10초 대기합니다.
  • 전체 경로 조회 실패 시 회색 점선과 직선거리만 표시합니다. 보행 안내·예상시간·점수·안심 타이머를 생성하지 않습니다.
  • route-navigation.js는 실제 도로망 응답으로 표시된 경로만 사용합니다. 도착 판정에는 경로상 남은 거리 25m 이내, 실제 목적지 거리 25m 이내, 경로 이탈 50m 미만, GPS 정확도 50m 이내가 함께 필요합니다.

AI 안내와 실제 실행

파일담당
chat.js채팅 화면, 실제 장소 후보 검색과 사용자 확인 흐름
chat-facility.js실제 GPS 재확인, 주변 공공시설 조회와 거리 계산, 조회 성공·부분 성공·실패 구분
chat-agent.js마지막에 로드되는 AI 진입점. 질문과 최근 대화·제한된 화면 요약을 Worker에 보내고 검증된 명령을 실제 기능에 연결
worker/ai-worker.mjs일반 답변·길찾기·주변 시설 의도 분류. 모델 출력 검증·보조 모델 재시도·응답 대기 제한·요청 크기 및 빈도 제한

AI가 실제 시설 좌표·거리·시설 수를 생성하지 않습니다. 브라우저의 조회 결과와 실패 상태를 대화 이력에 기록합니다. 화면에서 GPS 좌표와 보호자 번호를 자동 전송하지 않으며, 사용자가 입력한 질문과 최근 대화는 AI 서비스에 전송됩니다.

즐겨찾기와 과거 기능

  • audit.js: 현재는 즐겨찾는 장소의 기기 내 저장·표시·삭제 기능입니다. 시민 안전 평가 기능이 아닙니다.
  • havens.js: 제거된 안심 편의점 기능의 호환용 함수입니다. 외부 편의점 데이터를 조회하지 않습니다.
  • worker/audit-worker.js: 과거 공유 평가 서버의 보관 코드이며 현재 프런트엔드와 연결되지 않습니다.
  • chat-history.js, route-mobile-ux.js: 현재 index.html에서 로드하지 않는 보조 파일입니다.

검증과 배포

node --test tests/regression.test.mjs로 위치 거부·API 실패·페이지 제한·직선 대체·도착 오판정·AI 응답 오류를 재현합니다. 모의 응답 기반 검증이며 실제 GPS 수신·모바일 배치·외부 데이터의 정확성을 대신하지 않습니다.

GitHub Pages와 Cloudflare Worker는 배포가 분리되어 있습니다. AI 서버 배포 설정 및 제한 사항은 worker/README.md를 확인합니다.

기능별 기본 파일 뒤에 로드되는 UX 확장 파일이 전역 함수를 감쌉니다. 실제 실행 순서는 index.html의 script 태그를 기준으로 확인합니다.
